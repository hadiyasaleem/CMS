#### 3.4.1 Data Dictionary

The dictionary lists the major information entities and calculated summaries in alphabetical order, each with its type and purpose. Field-level detail is left out on purpose — this chapter explains the design, not the column layout — and the calculated summaries are derived from the base records rather than stored as separate tables.

**Table 3-4 — Alphabetical Data Dictionary**

| Terminology | Description, type, and role |
|---|---|
| Academic Session | Record. One department intake and shift; holds the current-semester pointer and the status, and anchors the students, subjects, fees, and timetable beneath it. |
| Administrator Account | Identity record. An authorised administrator — profile details, account status, and responsibility for approved actions. |
| Application Log | Operational record. Diagnostic entries the apps write for troubleshooting; not part of the academic data. |
| Assessment Mark | Academic record. A student's score for one subject and exam type, with the maximum (midterm 25, sessional 15) and the academic context it was recorded in. |
| At-Risk Student Summary | Calculated summary. Flags students whose attendance or standing falls below the college's review threshold, so authorised staff can follow up. |
| Attendance Record | Academic record. One student's present, absent, or leave status for a dated class meeting, with an optional late flag and note. |
| Attendance Summary | Calculated summary. Rolls class attendance up into present/absent/leave, total-marked, and percentage values. |
| Building | Master record. A named building on campus; its rooms are offered as a pick-list when a class period or exam is scheduled. |
| Calendar Event | Publication record. A holiday, event, exam period, or deadline — with dates and the audience allowed to see it. |
| Datesheet | Publication record. An examination schedule for one academic session and semester; a published flag controls whether that session's students can see it yet. |
| Datesheet Slot | Child record. One paper on a datesheet — subject, date, time, and a real building and room, with an optional invigilator. |
| Department | Master record. An academic department; the top-level grouping for sessions, teachers, and reports. |
| Examination Paper Submission | Academic file record. Links a teacher's submitted mid-term paper (a PDF in Storage) to a published datesheet slot; administrators can view or download it, with no separate review step. |
| Examination Statistics | Calculated summary. Entered-mark counts, average and range, and pass rate for an assessment, within the viewer's authority. |
| Fee Exception | Financial record. An authorised adjustment to an individual student's standard session fee. |
| Fee Heading | Financial child record. One line of a session's fee structure — a label and amount. |
| Fee Structure | Financial record. The charges, due date, payment note, and annual-or-semester cadence for one session. |
| Fine | Financial notice. An informational fine on a student — category, amount, reason, date, and issuer. It records no online payment and no paid/unpaid status. |
| Mark Correction Request | Approval record. The recorded score, the requested score, the teacher's reason, the review state, and the reviewer's decision and time. |
| Notification | Communication record. An in-app title and message with its audience (a role, optionally narrowed to a department or session); read state is tracked per viewer. There is no push service. |
| Period-Session Assignment | Relationship record. Links a timetable period to one or more sessions when a class is shared (a merged lecture). |
| Room | Master record. A room within a building, chosen when a timetable period or datesheet slot needs a location. |
| Semester Result | Academic outcome. A student's semester GPA, CGPA, result status, class position, and any supply (repeat) subjects. |
| Semester Term | Academic date record. The opening and closing dates of a semester within a session. |
| Session Overview | Calculated summary. Department, shift, semester, enrolment, attendance, and academic standing gathered into one session-level view. |
| Student | Person and enrolment record. Roll number, name, contact and guardian details, enrolment status, current standing, and the approved account link. |
| Student Account Link Request | Approval record. A registered account's claim to a student record — the claimed identity, the review state, and the final decision. |
| Student Progression Summary | Calculated summary. A student's semester-by-semester outcomes and changes in performance. |
| Subject | Academic record. A course code, name, credit value, theory-or-lab type, and the semester it is taught in, within a session's curriculum. |
| Teacher | Person and employment record. Identity, department, account status, contact details, and the delegated permissions an administrator has granted. |
| Timetable Period | Scheduling record. One slot on a session's weekly grid — day, time, period type, subject, teacher, and room. A database trigger prevents the same teacher or room being double-booked. |
| User Account | Identity record. The account's email, role, and status, and the approved person record used to open the correct workspace. |
