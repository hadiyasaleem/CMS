#### 2.3.7 FR-7: Manage Teachers and Permissions

**Table 2-28 — Description of FR-7**

| Field | Detail |
|---|---|
| Identifier | FR-7 |
| Title | Manage Teachers and Permissions |
| Requirement | An administrator shall be able to create teacher accounts, view and update permitted teacher details, reset a teacher's password, and disable, ban, or reactivate an account with confirmation. The administrator shall also grant or remove a teacher's delegated permissions — approving student link requests, editing the timetable, sending notifications, and managing datesheets. Invalid or duplicate account details shall not be saved. |
| Source | College administration |
| Rationale | Teaching access and any delegated duties stay under administrative control, so a teacher holds only the extra powers an administrator has explicitly granted. |
| Business Rule | Only an administrator may change a teacher's status or permissions; a status change preserves the teacher's historical teaching records. |
| Dependencies | FR-1 |
| Priority | High |
