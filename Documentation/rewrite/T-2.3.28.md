#### 2.3.28 FR-28: Review Student Link Request

**Table 2-49 — Description of FR-28**

| Field | Detail |
|---|---|
| Identifier | FR-28 |
| Title | Review Student Link Request |
| Requirement | An administrator, or a teacher granted the approve-link-requests permission, shall be able to compare a pending link request against the college roster and approve or reject it. A decided request cannot be processed again, and a failed decision leaves it pending. An administrator may also revoke or re-link a record later; doing so downgrades the previous account's now-stale approval so a record is never left with two active links. |
| Source | College administration and teaching staff |
| Rationale | An independent check keeps a student record from being linked to the wrong account — and keeps exactly one account attached to it over time. |
| Business Rule | Approval links one account to one matching student record; rejection records the decision without linking; a record has at most one live approved link, and re-linking or delinking clears the earlier one. |
| Dependencies | FR-27 |
| Priority | High |
