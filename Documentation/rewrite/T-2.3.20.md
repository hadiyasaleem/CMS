#### 2.3.20 FR-20: Manage Session Fee Structure

**Table 2-41 — Description of FR-20**

| Field | Detail |
|---|---|
| Identifier | FR-20 |
| Title | Manage Session Fee Structure |
| Requirement | An administrator shall be able to set a session's fee structure — the fee heads and their amounts, the cadence (annual or per-semester), the due date, a late-fine note, and a payment note — and update it later. The system shall reject negative amounts, missing required fee information, and invalid dates before saving. |
| Source | College administration and accounts office |
| Rationale | A student's challan can only be shown once the session's fee structure has been agreed and entered. |
| Business Rule | A fee structure belongs to one session and is set only by an administrator; the payment note makes clear that fees are paid at the college accounts office, never through the app or a bank. |
| Dependencies | FR-4 |
| Priority | High |
