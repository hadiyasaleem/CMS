#### 3.5.1 Screen Images

The mobile images are captured from working builds; the desktop images are representative views generated from the implemented desktop navigation and screen structure. Between them they show each of the six apps from its own role's perspective, all in the shared "Modernist" design.

**3.5.1.1 Admin Mobile Application** — the dashboard gives the administrator an immediate college summary and short routes into academic, people, record, and approval work. *(Figure 3-6 — Admin Mobile dashboard)*

**3.5.1.2 Admin Desktop Application** — the same administrative areas, using a permanent navigation rail and wider information cards for office work. *(Figure 3-7 — Admin Desktop representative interface)*

**3.5.1.3 Teacher Mobile Application** — the home screen leads with today's classes and the actions normally needed during a lesson, attendance and assessment. *(Figure 3-8 — Teacher Mobile home screen)*

**3.5.1.4 Teacher Desktop Application** — the same assigned work with room for larger rosters, mark-entry tables, and schedules, plus desktop file and print actions. *(Figure 3-9 — Teacher Desktop representative interface)*

**3.5.1.5 Student Mobile Application** — the home screen summarises the current semester and gives direct access to the student's own academic information, with no administrative controls. *(Figure 3-10 — Student Mobile home screen)*

**3.5.1.6 Student Desktop Application** — the same personal information in a wider reading layout, with open, save, and print actions. *(Figure 3-11 — Student Desktop representative interface)*
