#### 2.5.3 Hardware Interfaces

The apps need no specialised hardware — ordinary Android phones and desktop computers, with a printer only where a challan or report is printed.

**Table 2-61 — Hardware Interfaces**

| Hardware | Applications | Interface requirement |
|---|---|---|
| Android phone or tablet | Admin Mobile, Teacher Mobile, Student Mobile | A touch display, enough local storage for the app, its Room cache, and any generated PDF, and network access. A camera or photo gallery is used only when a profile photo is set; no biometric reader or specialist sensor is required. Runs on Android 7.0 or later. |
| Desktop computer (Windows, on the JVM) | Admin Desktop, Teacher Desktop, Student Desktop | Keyboard and pointing-device input, a display suitable for responsive application windows, local storage, and network access. A Java runtime is required, since the desktop apps run on the JVM. |
| Printer | The three desktop apps, where Print is offered | Receives a user-approved print job — a fee challan or report — through the operating-system print dialog. The app stays usable when no printer is installed. |
| Local or removable storage | Apps that open, upload, save, or download files | A user-selected file or destination; the app never assumes access to a fixed personal folder. |
