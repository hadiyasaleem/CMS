#### 2.3.27 FR-27: Submit Student Link Request

**Table 2-48 — Description of FR-27**

| Field | Detail |
|---|---|
| Identifier | FR-27 |
| Title | Submit Student Link Request |
| Requirement | A registered but unlinked student shall be able to claim their college record by submitting the roll number — chosen from the list of unclaimed roll numbers for their session — together with identity details (CNIC/B-form, name, and date of birth) for an authorised reviewer to check. The system shall refuse an unknown record, a mismatch, a second request while one is already pending, or a record that is already linked. The rest of the app stays gated until the request is approved. |
| Source | Students and college administration |
| Rationale | Self-registration must never hand a student access to someone else's academic record, so a claim is checked against the college roster before anything opens. |
| Business Rule | One account links to one student record, and each student record has at most one approved account; a request moves through pending, approved, or rejected. |
| Dependencies | FR-1, FR-6 |
| Priority | High |
