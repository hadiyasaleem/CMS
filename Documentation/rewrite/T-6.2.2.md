#### 6.2.2 Training

Training is organised by role, and by the actual task each person does rather than a tour of every screen. Each session is a short demonstration on pilot records, then supervised practice, then a quick check that the learner can do the task unaided. Mobile and desktop users get the same instructions for the work itself — the rules and decisions are identical — and only the Windows-specific steps differ, mainly how a file is saved or printed. Someone is trained as ready when they can repeat their task without help, recognise the warning and empty-state messages, and know who to contact when a record looks wrong.

**Table 6-5 — Training coverage**

| Audience / role | What they are trained on | Walkthrough |
|---|---|---|
| Admin (mobile + desktop) | Create people and academic records, set up rosters, manage schedules and fees, review link and mark-correction requests, read dashboard figures | Includes generating the fee challan on desktop (Use Case 2) |
| Teacher (mobile + desktop) | Open assigned classes, record attendance and marks (midterm /25, sessional /15), raise a mark correction, read schedules and notices | Recording attendance (Use Case 1) |
| Student (mobile + desktop) | Link the account to a college record, then read personal attendance, marks, timetable, datesheet, fees, and notices | Account linking and reading the fee challan |
| Desktop-specific steps | Choosing a save location, saving/exporting a record, and printing to a selected printer | The native save/print dialog in Use Case 2 |

**Use Case 1 — Record class attendance** *(Teacher Mobile and Desktop)*

The same labels and decisions appear in both versions; the wider desktop window only gives more viewing space.

1. Sign in to the Teacher app and open Attendance.
2. Select the assigned class for the date; if none is selected, the app asks the teacher to choose one.
3. Review the class name, date, roster total, and any attendance already recorded.
4. Mark every student Present, Absent, or Leave, setting the late flag or a note where needed — a late student stays Present with the late flag, not a separate status.
5. Confirm every student is marked, submit the register, and open Attendance History to review or check an earlier record.

**Use Case 2 — Generate and print the fee challan** *(Admin Desktop)*

1. Sign in to the Admin Desktop app and open the session's Fees screen.
2. Select the student (or the sample) and generate the challan.
3. The app builds a three-copy challan PDF — student, college, and clerk copies.
4. In the native save dialog, choose where to save it, or send it to a printer; cancelling writes nothing and changes no college data.
5. The saved file opens in the default viewer for a final check before it is printed and issued.
