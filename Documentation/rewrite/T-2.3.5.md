#### 2.3.5 FR-5: Manage Curriculum

**Table 2-26 — Description of FR-5**

| Field | Detail |
|---|---|
| Identifier | FR-5 |
| Title | Manage Curriculum |
| Requirement | An administrator shall be able to add, view, update, and remove the subjects that make up a session's curriculum, semester by semester. Each subject carries a course code, name, credit hours, and a THEORY or LAB type, and may be marked elective; the system shall validate these details and refuse a duplicate course code within the same session and semester. |
| Source | College administration and teaching staff |
| Rationale | Attendance, marks, timetables, and results all attach to a subject, so the curriculum has to be agreed before any of them can be recorded. |
| Business Rule | Every subject belongs to one session and semester; a course code is unique within that session and semester. |
| Dependencies | FR-4 |
| Priority | High |
