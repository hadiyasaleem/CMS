#### 2.3.4 FR-4: Manage Academic Sessions

**Table 2-25 — Description of FR-4**

| Field | Detail |
|---|---|
| Identifier | FR-4 |
| Title | Manage Academic Sessions |
| Requirement | An administrator shall be able to create, view, update, and promote academic sessions within a department. The system shall check the session's year, shift, and semester before saving and reject duplicate or inconsistent details. Promoting a session advances it to the next semester — and graduates it after the eighth — while a completed session can be archived and removed. |
| Source | College administration |
| Rationale | Students, curriculum, timetables, fees, and results are all organised by academic session, so the session is the unit the rest of the academic year is built around. |
| Business Rule | A session belongs to one department and may advance only within its permitted semester range, up to graduation at semester 8. |
| Dependencies | FR-3 |
| Priority | High |
