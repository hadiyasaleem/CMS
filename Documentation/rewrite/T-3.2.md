### 3.2 Design Models

The design is captured in three complementary models, each taken up in a subsection below. The domain and class relationship model (§3.2.1) lays out the main information objects and how they connect. The interaction models (§3.2.2) trace the order in which a user, an app, and the shared backend cooperate to get something done. The state-transition models (§3.2.3) follow how approval and publication records move from one state to the next. Between them they cover structure, behaviour, and change without tying any of it to a particular programming language.
