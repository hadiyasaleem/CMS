### 2.1 User Classes and Characteristics

The system has three kinds of user — administrator, teacher, and student — and each works in both a mobile and a desktop app, which gives six user classes in all. The same person may use both device types; they are listed separately because the setting, the screen size, and the file and printing actions available differ between a phone and a desktop. Table 2-1 describes each.

**Table 2-1 — User Classes and Characteristics**

| User Class | Characteristics |
|---|---|
| Admin Mobile User | An authorised administrator who needs quick access to summaries, approvals, people, academic records, notices, and reports while moving around the college. Actions are limited to what the account permits. |
| Admin Desktop User | The same administrator doing longer office work at a desk — managing large lists, timetable and fee work, and report review — with exporting and printing. |
| Teacher Mobile User | A faculty member using a phone through the teaching day to check classes, mark attendance, enter marks, request a correction to a locked mark, submit exam papers, record results, and read college information. |
| Teacher Desktop User | The same teacher doing that work at a desk, with more room for class registers, marks grids, schedules, and student lists, plus desktop file and print actions. |
| Student Mobile User | An enrolled or newly registered student using a phone to link their account and then check their own attendance, timetable, marks, results, fees, datesheets, and notices. |
| Student Desktop User | The same student on the desktop, using the larger screen to read their records and to download or print the fee challan. |
