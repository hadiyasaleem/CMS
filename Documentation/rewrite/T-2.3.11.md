#### 2.3.11 FR-11: View Attendance History

**Table 2-32 — Description of FR-11**

| Field | Detail |
|---|---|
| Identifier | FR-11 |
| Title | View Attendance History |
| Requirement | A teacher shall be able to review attendance history for their assigned classes, an administrator shall be able to review authorised attendance reports, and a student shall be able to see only their own attendance — a per-subject present/absent/leave breakdown with an attendance percentage they can check against the 75% requirement. Where nothing has been recorded, the app shall show an empty state rather than reporting zero attendance. |
| Source | All user classes |
| Rationale | Attendance is only useful if the right person can review it in time — the teacher for their classes, the administration across the college, and the student for their own standing. |
| Business Rule | What each user sees follows their role, teaching assignment, session, and linked student identity. |
| Dependencies | FR-10, FR-27 |
| Priority | High |
