## 4. Implementation

This chapter shows how the main features actually work, without reprinting source code. The key algorithms are written as language-neutral pseudocode, so their decisions, inputs, outputs, and cost can be judged on their own rather than through Android or desktop specifics (§4.1). It then records the external services the six apps depend on (§4.2) and the current state of the shared Git repository, including contributor activity (§4.3). The coding standards the project follows are collected in Appendix B.
