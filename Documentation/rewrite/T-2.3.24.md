#### 2.3.24 FR-24: Manage Calendar Events

**Table 2-45 — Description of FR-24**

| Field | Detail |
|---|---|
| Identifier | FR-24 |
| Title | Manage Calendar Events |
| Requirement | An administrator shall be able to create, update, and remove college calendar events — each with a title, a type, a date or date range, optional start and end times, a venue, a description, and an audience. The system shall reject an invalid date range, a missing title, or incomplete audience information before saving. |
| Source | College administration |
| Rationale | Holidays, examinations, deadlines, and events belong on one current college calendar rather than scattered across notices. |
| Business Rule | An event's audience decides who sees it — everyone, a particular role, a department, or a session; a college-wide event leaves the department and session unset. |
| Dependencies | FR-1 |
| Priority | Medium |
