#### 2.3.3 FR-3: Manage Departments

**Table 2-24 — Description of FR-3**

| Field | Detail |
|---|---|
| Identifier | FR-3 |
| Title | Manage Departments |
| Requirement | An administrator shall be able to create, view, and update departments from the admin apps. A department with a missing or duplicate identifier shall not be saved, and deleting one shall require confirmation — because removing a department also removes the academic sessions beneath it and everything those sessions hold. |
| Source | College administration |
| Rationale | A department sits at the top of the structure: sessions, people, and academic records all hang beneath it. It has to exist before any of them, and be removed with care. |
| Business Rule | Each department has a unique identifier and a clear display name. |
| Dependencies | FR-1 |
| Priority | High |
