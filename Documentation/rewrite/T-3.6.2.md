#### 3.6.2 Publish College Information

An administrator — or a teacher with the matching permission — composes an item in the admin or teacher app: a datesheet, a calendar event, a notification, or a fee or fine record. The view model checks the required fields and the chosen audience before anything is saved, and the repository then writes it to Supabase. Once it is published, only the roles or academic groups it is addressed to can see it in their own apps. The same flow serves every kind of published item, so they are all validated and stored the same way.
