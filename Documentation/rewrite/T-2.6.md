### 2.6 Summary

This chapter turned the project overview into a set of requirements the finished system can be checked against. Six user classes cover administrators, teachers, and students on both mobile and desktop; twenty fully dressed use cases and their diagrams show how each carries out their main work; and thirty-three functional requirements define the services and the failure behaviour expected of the system — two of them (the Documents feature) now withdrawn as the system no longer includes it. Reliability, usability, performance, security, and the external-interface requirements set measurable conditions across all six applications. Together these form the reference point for the design in Chapter 3 and for the testing and evaluation later in the report.
