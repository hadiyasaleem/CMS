#### 4.1.8 Build a Student Academic Overview

A student's home brings everything about their own record into one view. It is assembled on the device from the base records the student is allowed to see — the same row-level rules that protect the data also scope it — rather than from a prepared server summary. Absent or unpublished values are shown as such, never as a misleading zero.

**Algorithm 8 — Build a student academic overview**
- *Input:* the approved student link and the current session
- *Output:* a home summary — attendance, schedule, marks, results, fees, and notices
- *Cost:* O(C + A + M + R) over the courses, attendance entries, marks, and result records used

1. Start once the student account is linked.
2. Load the student's current session, semester, subjects, and timetable.
3. Load only that student's own attendance, marks, semester results, fees, fines, and the publications meant for them.
4. Work out per-subject attendance percentages (against the 75% line) and find the next scheduled class.
5. Take current standing — GPA, CGPA, and any supply subjects — from the latest completed result.
6. For marks, show midterm out of 25, sessional out of 15, and the total, marking an unentered or absent value plainly rather than as zero.
7. If one information group is unavailable, show the rest and a retry for the missing group.
8. Present the same information in the mobile or desktop layout and stop.
