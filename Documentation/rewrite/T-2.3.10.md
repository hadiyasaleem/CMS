#### 2.3.10 FR-10: Mark Attendance

**Table 2-31 — Description of FR-10**

| Field | Detail |
|---|---|
| Identifier | FR-10 |
| Title | Mark Attendance |
| Requirement | An assigned teacher shall be able to select one of their classes and a date, mark each enrolled student present, absent, or on leave — flagging a present student as late where needed — review the totals, and submit the register. Incomplete entries, a duplicate register for the same meeting, an unassigned class, and a failed submission shall each be identified clearly. |
| Source | Teaching staff and college administration |
| Rationale | A digital register replaces manual counting and makes the same record available to the student and to administrative reports without re-entry. |
| Business Rule | One final status — present, absent, or leave — is stored per student for each class meeting, with an optional late flag. Only the assigned teacher may write attendance; an administrator can read it for reports but never records or edits it. |
| Dependencies | FR-6, FR-8 |
| Priority | High |
