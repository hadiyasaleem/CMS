#### 2.3.14 FR-14: Review Mark Correction

**Table 2-35 — Description of FR-14**

| Field | Detail |
|---|---|
| Identifier | FR-14 |
| Title | Review Mark Correction |
| Requirement | An administrator shall be able to open a pending mark-correction request, see the old and proposed values side by side, read the teacher's reason, and approve or reject it. A request that has already been decided cannot be decided again, and if the decision fails to save, the original mark and the request's status are both left untouched. |
| Source | College administration |
| Rationale | An independent second look at any change to a submitted mark is what keeps the assessment record trustworthy. |
| Business Rule | The teacher who raised the request cannot approve it; approving records the decision and applies exactly the proposed value — nothing else. |
| Dependencies | FR-13 |
| Priority | High |
