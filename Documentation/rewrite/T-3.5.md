### 3.5 User Interface Design

The interface is organised around the work each role performs. Administrators see college-wide totals, academic structure, people, approvals, records, and reports; teachers see their assigned classes, attendance, assessment, schedules, students, and the college information they are permitted; students see only their own attendance, timetable, marks, results, fees, notices, and profile. On mobile the layout is compact — bottom navigation and vertically arranged cards — while the desktop uses the extra width for wider cards, tables, and file or print actions.

The wording and meaning of an action never change between devices: a teacher opening Mark Attendance goes through the same class, subject, roster, validation, and confirmation steps on a phone and on a desktop, and only the arrangement differs. That consistency is possible because all six apps are built from one shared component library — the "Modernist" design system on Material 3, each app carrying its own signature accent. The subsections that follow show representative screens (§3.5.1), the objects and actions on two key screens (§3.5.2), and the feedback and interaction rules every screen shares (§3.5.3).
