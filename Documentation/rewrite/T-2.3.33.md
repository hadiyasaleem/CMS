#### 2.3.33 FR-33: Use Desktop File and Print Services

**Table 2-54 — Description of FR-33**

| Field | Detail |
|---|---|
| Identifier | FR-33 |
| Title | Use Desktop File and Print Services |
| Requirement | The Admin, Teacher, and Student desktop apps shall offer role-appropriate file services through the operating system's own dialogs — choosing a file to open, picking a save location, exporting a report to CSV or PDF, printing a challan or record, and sharing where supported. Cancellation, a missing application or printer, insufficient permission, or an unsupported file shall return a clear result without changing college data. |
| Source | Desktop user classes |
| Rationale | At a desk, users expect these file, export, and print steps to run through the familiar operating-system dialogs rather than a bespoke in-app version. |
| Business Rule | A desktop file action never bypasses the app's access rules; the native operating-system windows sit outside the app's own visual design. |
| Dependencies | FR-1, plus the requirement that owns the record being exported or printed |
| Priority | Medium |
