#### 2.3.2 FR-2: Manage Administrator Accounts

**Table 2-23 — Description of FR-2**

| Field | Detail |
|---|---|
| Identifier | FR-2 |
| Title | Manage Administrator Accounts |
| Requirement | An administrator shall be able to see the existing administrators and add or maintain another administrator account from either admin app. The system shall validate the required identity and contact details, refuse a duplicate account, and make sure a failed creation leaves no partial account behind. |
| Source | College administration |
| Rationale | The college needs to share administrative work across more than one person without anyone setting up accounts outside the system. Creating them in-app keeps that under an existing administrator's control. |
| Business Rule | Only an active administrator may grant administrative access; an account's email and identity must be unique. |
| Dependencies | FR-1 |
| Priority | High |
