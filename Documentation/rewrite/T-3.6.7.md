#### 3.6.7 Mark Correction Request States

A saved mark is locked. A teacher's correction request against it creates a pending review, and only one request can be pending for a mark at a time. An administrator — never the teacher who raised it — approves the request, which applies the proposed value, or rejects it, which leaves the original mark unchanged. Either way the decision is final and kept, so the mark's history can be traced later.
