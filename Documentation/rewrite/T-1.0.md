## 1. Introduction

Before the later chapters get into requirements, design, implementation, testing, and deployment, this chapter sets the ground the rest of the report stands on. It begins with the problem at Govt. Graduate College, Mandi Bahauddin — an academic routine still run largely on paper — and the solution that answers it, then fixes the objectives and scope that everything afterward is measured against. From there it introduces the six applications that make up the system: an admin, a teacher, and a student app, each shipped on both Android and desktop. It places those against the related systems already in use, and closes with the project's vision, the limitations and constraints it works within, and the tools, deliverables, and plan behind the build.
