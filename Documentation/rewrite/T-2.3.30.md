#### 2.3.30 FR-30: View Notifications

**Table 2-51 — Description of FR-30**

| Field | Detail |
|---|---|
| Identifier | FR-30 |
| Title | View Notifications |
| Requirement | A signed-in user shall be able to see the notifications addressed to their role or academic group, open one for its full detail, and see a badge with their unread count. Notifications meant for other audiences shall not appear, and a loading failure shall offer a retry. |
| Source | All user classes |
| Rationale | Everyone needs one consistent place to find current college alerts rather than checking a noticeboard. |
| Business Rule | What a user sees follows each notification's target audience; the read/unread state is kept per viewer, so opening a notification clears it for that user alone and does not change it for anyone else. |
| Dependencies | FR-29 |
| Priority | Medium |
