### 1.10 Project Deliverables

The project hands over:

- This report and its appendices — the fully dressed use cases (Appendix A), the coding standards the project follows (Appendix B), and the application prototype (Appendix C) — along with the planning, requirements, and design material and the test records behind them.
- Six installable applications: the Admin, Teacher, and Student apps as Android packages, and the same three as Compose-for-Desktop builds.
- The configured Supabase project that backs them — the database schema, the Row-Level Security policies, and the file-storage buckets.
- The complete source for all six apps and the shared modules they are built from (`core`, `mobile-shared`, and `desktop-shared`).
