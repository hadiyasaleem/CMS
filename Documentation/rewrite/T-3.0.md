## 3. System Design

The College Management System is a family of six applications rather than one big interface: an admin, a teacher, and a student app, each on both a phone and a desktop, all sharing the same college records and business rules so that an action taken on one device shows up wherever that authorised information appears. Behind them sit managed services for accounts, the database, file storage, and email.

The rest of the chapter shows how those parts fit together — the design constraints and risks, the main information objects and how they relate, the architecture that ties the six apps to one backend, the data organisation, the user interfaces, the key interactions and workflow states, and the design decisions that keep mobile and desktop behaving the same.
