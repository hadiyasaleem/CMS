#### 2.3.13 FR-13: Request Mark Correction

**Table 2-34 — Description of FR-13**

| Field | Detail |
|---|---|
| Identifier | FR-13 |
| Title | Request Mark Correction |
| Requirement | A teacher responsible for a locked mark shall be able to propose a corrected value and give a reason for the change. The system shall reject an out-of-range value, a missing reason, or a second request while one is already pending, and shall leave the original mark in place until the request is decided. |
| Source | Teaching staff and college administration |
| Rationale | Genuine mistakes have to be fixable, but a submitted mark should never change quietly — a correction leaves a visible, reviewable trail. |
| Business Rule | A locked mark changes only after an administrator approves the request; the teacher who raises a correction cannot approve it, and only one request may be pending for a mark at a time. |
| Dependencies | FR-12 |
| Priority | High |
