#### 2.3.15 FR-15: Record Semester Results

**Table 2-36 — Description of FR-15**

| Field | Detail |
|---|---|
| Identifier | FR-15 |
| Title | Record Semester Results |
| Requirement | An assigned teacher shall be able to record each student's semester result — GPA, CGPA, result status, class position, any carried supply (retake) subjects, and remarks — for a given semester and term. The system shall flag missing students, out-of-range values, and incomplete entries before the result is saved. |
| Source | Teaching staff and college administration |
| Rationale | Students and administrators need one agreed semester-level outcome per student, recorded through a single controlled path so GPA and CGPA stay consistent everywhere they appear. |
| Business Rule | Results may be recorded only for the teacher's assigned session and semester, using allowed academic values; every result is written through the one controlled result path, which is the only way a teacher can set a GPA. |
| Dependencies | FR-5, FR-6, FR-8 |
| Priority | High |
