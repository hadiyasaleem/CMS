#### 2.3.6 FR-6: Manage Students and Session Rosters

**Table 2-27 — Description of FR-6**

| Field | Detail |
|---|---|
| Identifier | FR-6 |
| Title | Manage Students and Session Rosters |
| Requirement | An administrator shall be able to add students one at a time or import a whole roster, view each student's card and profile, and update valid details. The system shall report duplicate roll numbers, missing required identity information, and invalid import rows without silently overwriting existing students, and shall keep a roster within its session's capacity. |
| Source | College administration and teaching staff |
| Rationale | Attendance, marks, fees, and account linking all depend on an accurate list of the students actually enrolled in a session. |
| Business Rule | A roll number identifies one student within a session; a student's enrolment status — active, promoted, repeated, withdrawn, or graduated — is carried across terms, and editing profile details never discards academic history. |
| Dependencies | FR-4 |
| Priority | High |
